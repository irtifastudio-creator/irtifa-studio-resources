# Proje Portföyü

Bu klasöre yalnızca gerçek, tamamlanmış veya durumu açıkça belirtilmiş ve yayınlanmasına izin alınmış projeler eklenmelidir.

Her proje için önerilen dosya yapısı:

```text
proje-adi/
├── README.md
└── images/
```

Proje sayfasında şu bilgiler yer alabilir:

- Proje adı ve kategori
- Projenin amacı
- İrtifa Studio'nun rolü
- Kullanılan teknolojiler (doğruysa)
- Yayınlanabilir ekran görüntüleri
- Sonuçlar (yalnızca ölçülmüş ve doğrulanmışsa)

Konsept çalışmalar “Konsept çalışma” olarak açıkça belirtilmelidir.
